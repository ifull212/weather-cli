# Weather CLI

A simple command-line weather tool using OpenWeatherMap API.

## Usage
```
python weather.py "London"
python weather.py "Tokyo" --imperial
```

## Features
- Current temperature, humidity, wind speed
- Metric (°C) and Imperial (°F) units
- Clean terminal output

## Setup
1. Get API key from openweathermap.org
2. Set `API_KEY` in weather.py
3. `python weather.py "Your City"`
